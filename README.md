Number Guessing Game :

This is a simple command line game written in Python. The computer will create a random number between 1-9. The player has to guess the number. (I used Visual Studio Code)

How to play:

Make sure you have python 3 installed. Then downlode this file:

python game.py

Rules

The player must guess a number between 1-9. There are 4 guesses. If they guess incorrectly the game will tell them to guess higher or lower depending on their answer and how many guesses they have left. If they run out of guesses then the game ends. Any numbers outside of 1-9 will be counted as a wrong guess. If the player types something that isn't a number they will see an error message. They won't lose a guess. The player can type 0 to quit at any point.
